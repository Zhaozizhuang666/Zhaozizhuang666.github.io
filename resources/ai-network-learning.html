容量规划速算

每 GPU 配 1 张 400G 网卡8 卡服务器需 8×400G = 3.2T 接入带宽
Leaf 下行每服务器 8×400G；上行若 1:1 收敛，需同样 3.2T 上行 = 8×400G 上行口
Spine 数量N 个 Leaf，每个 Leaf 接全部 Spine；Spine 数决定无阻塞程度
万卡粗算8 卡/服务器 → 1250 台；每 Leaf 接 16 台 → ~78 台 Leaf；Spine 按上联带宽反推

术语速查表

缩写全称含义
PCIePeripheral Component Interconnect Express通用高速串行总线，GPU 与 CPU/内存相连
NVLinkNVIDIA LinkNVIDIA 私有 GPU 间高速互联，节点内使用
NVSwitch—NVLink 的交叉交换芯片，支持多 GPU full-mesh
SXMServer ModuleGPU 直插主板的高功率形态（vs PCIe 插卡）
HGX—NVIDIA 8-GPU 服务器模组
RDMARemote Direct Memory Access远程直接内存访问，零拷贝、内核旁路
RNICRDMA NIC支持 RDMA 的网卡（如 Mellanox ConnectX）
HCAHost Channel AdapterInfiniBand 主机通道适配器（即 IB 网卡）
RoCERDMA over Converged Ethernet以太网上跑 RDMA；v1 二层、v2 三层（UDP/4791）
IBInfiniBand原生 RDMA 网络，由 SM 管理
PFCPriority-based Flow Control基于优先级的以太网逐跳流控（802.1Qbb）
ECNExplicit Congestion NotificationIP 头显式拥塞通知（RFC 3168）
CNPCongestion Notification PacketRoCEv2 中接收端返回给发送端的拥塞通知包
DCQCNData Center QCNRoCEv2 事实标准端到端拥塞控制算法
TIMELY—基于时延的 RDMA 拥塞控制算法
NCCLNVIDIA Collective Communications LibraryNVIDIA 多 GPU 集合通信库
AllReduce—所有 GPU 对同一张量做归约后再分发给所有 GPU
Ring AllReduce—环形全归约，带宽最优，大消息首选
DBTDouble Binary Tree树形全归约，延迟最优，小消息首选
Spine-Leaf—现代数据中心两层 Clos 拓扑
PODPoint of Delivery集群内的一个故障/管理域
Rail—一张网卡对应一条水平轨道（Rail-optimized 拓扑）
SHARPScalable Hierarchical Aggregation and Reduction ProtocolNVIDIA IB 交换机上的在网计算
SuperNIC—NVIDIA 支持 GPUDirect RDMA 的高性能网卡
