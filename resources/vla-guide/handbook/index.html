m1-01

数学最小集

本章重点
矩阵表示线性变换；条件概率描述已知信息后的不确定性；刚体变换把不同坐标系的几何量接起来。
公式 / 方法
x′ = Rx + t；T = [R t; 0 1]；p(A|B) = p(A,B) / p(B)
解析
R 是 3×3 旋转矩阵、t 是 3 维平移。齐次矩阵 T 为 4×4，乘 4 维列向量 [x;1]。条件概率公式要求 p(B)>0。变换组合的乘法次序不能交换。
备注
旋转矩阵满足 RᵀR=I、det(R)=1。坐标轴方向、长度单位和相机时间必须统一；考研数学不能完整替代机器人几何。
自测
给点 (1,0,0) 施加绕 z 轴 90° 旋转，再平移 (1,2,0)，手算得到 (1,3,0)，用代码核对。

m2-01

骨干网络与注意力机制

本章重点
残差支路提供直接信息路径；自注意力根据查询与键的相似度聚合值。
公式 / 方法
Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V；y = x + F(x)
解析
若 Q、K 为 n×dₖ，QKᵀ 是 n×n，softmax 通常沿键维；V 为 n×dᵥ，输出 n×dᵥ。缩放在独立分量假设下抑制点积方差随维度增长。
备注
残差相加需形状一致；注意力 mask 必须在 softmax 前正确应用；自注意力不自动包含位置信息。
自测

本章重点

公式 / 方法
IoU = |预测区域 ∩ 真实区域| / |预测区域 ∪ 真实区域|
解析

m2-03

扩散模型基础

本章重点
前向过程向数据加噪；去噪网络在条件下恢复可采样的分布。
公式 / 方法
xₜ = √ᾱₜ x₀ + √(1−ᾱₜ) ε；L = E‖ε − εθ(xₜ,t,c)‖²
解析
ε 是标准高斯噪声，ᾱₜ 是累计保留信号系数，c 是条件。此处是 DDPM 常见噪声预测参数化，训练采样 t 后回归所加噪声。
备注
扩散、score 建模与 flow matching 有联系，但目标和路径不等同；π 系列不能简单归为 DDPM。
自测
画出不同 t 的信噪比，并说明训练时知道 ε、采样时不知道 x₀。

m3-01

图文对齐

本章重点
图文对齐用成对数据学习可比较的嵌入，关键在相似度、正负样本和损失。
公式 / 方法
Lᵢ = −log [exp(sᵢᵢ/τ) / Σⱼ exp(sᵢⱼ/τ)]
解析
sᵢⱼ 为归一化图像与文本嵌入的相似度，τ 为温度。此式是单方向 softmax 对比损失，CLIP 常对两个方向平均；SigLIP 使用不同的成对 sigmoid 目标。
备注
“相似”不代表几何可执行，也不等于物理理解。模型版本中编码器结构应以实际配置核对。
自测
构造同义文本被当成负例的 batch，解释假负样本如何改变梯度。

action-geometry

动作、坐标系与控制频率

本章重点
位姿组合必须声明从哪个坐标系到哪个坐标系，动作表示与控制模式也要分开。
公式 / 方法
pᴮ = Tᴮ_C pᶜ；Tᴮ_E = Tᴮ_C Tᶜ_E；Δt = 1 / f
解析
上标是目标系、下标是源系。齐次坐标相乘可串联变换；f 为 Hz 时 Δt 单位为秒。10 Hz 的新观测每 0.1 秒到达，不能假设对应控制内环频率。
备注
绝对位姿、增量位姿、关节位置和力矩语义不同；旋转增量的左乘右乘代表不同约定。
自测
使用已知基准点验证正向和逆向变换，并检查厘米和米混用的影响。

flow-matching

Diffusion 与 Flow Matching 的区别

本章重点
比较概率路径、回归目标和采样方程，避免把所有连续生成过程叫成同一种扩散。
公式 / 方法
xₜ = (1−t)x₀ + t x₁；L_FM = E‖vθ(xₜ,t,c) − (x₁−x₀)‖²
解析
这是一种线性条件路径的示例：x₀ 为噪声，x₁ 为数据，目标速度是路径导数。采样从噪声出发积分 dx/dt=vθ。其他耦合和路径会改变目标。
备注
时间方向在论文中可能相反；比较公式前统一 t 的定义。不能据此断言任何 FM 模型都优于扩散。
自测
用二维点分布画出线性路径，说明条件速度与边缘向量场的关系。

Diffusion Policy 最小实践

本章重点
Push-T 实践重点是观测窗口、动作窗口、执行窗口和受控比较。
公式 / 方法
