评测协议与结果可信度

让成功率具备可比较的含义，并报告失败与不确定性。

STUDY NOTES / 先读重点

重点、公式与解读

本章重点
成功率是带任务分布、成功定义和样本量的估计；同时看区间与失败分组。
核心公式
p̂ = k/n；SE ≈ √[p̂(1−p̂)/n]
怎么理解
k 为成功数，n 为有效试验数。SE 是独立伯努利且样本足够时的近似标准误；边界或小样本可用 Wilson 区间，相关试验应按场景或种子考虑聚类。
阅读备注
不要把近似正态区间用于极小样本或全成功来声称确定性。
动手自测
固定 n=100，比较 80 成功与 83 成功：说明还需要区间、配对信息与重复种子。

固定协议再运行

明确 benchmark 版本、任务子集、初始状态、随机种子、每任务 rollout 数、最大步数、成功判定和 checkpoint 选择方式。控制频率、相机分辨率、动作后处理与环境 wrapper 也属于协议。

平均成功率可能掩盖什么

先分别报告每任务结果，再给宏平均。任务数不均时，直接合并所有 rollout 得到的是不同权重的微平均。测试 n 次成功 k 次的 k/n 是估计值，建议报告 Wilson 区间或合适的 bootstrap 区间。多次 rollout 来自同一任务时存在相关性，不能简单当作完全独立证据。

域内与域外分开

  • 已见场景与任务的复现评测，检验是否正确跑通。
  • 新物体、新背景、视角或语言改写，检验具体维度的泛化。
  • 跨任务或跨本体迁移，需要检查预训练数据重叠。
  • 仿真成绩支持仿真内结论，不能直接推导真机安全性。

完整保留失败

按感知、语言理解、到达、抓取、碰撞、长程规划和超时等类别分析，同时允许未知原因。对同一初始状态比较模型，以便定位差别。公开视频时保留抽样规则，不只挑最好的几段。
