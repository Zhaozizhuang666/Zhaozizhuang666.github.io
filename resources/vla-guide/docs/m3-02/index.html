基础

视觉接入语言模型

三种主流桥接方式：交叉注意力、Q-Former、线性投影。理解各自的取舍。

原稿整合约 5 分钟 · 不含实践更新于 2026-10-23
STUDY NOTES / 先读重点

重点、公式与解读

本章重点
接入视觉需要将图像特征转成语言模型能消费的 token 或交叉注意力条件。
核心公式
Z = Pθ(Eᵥ(I))；p(y|I,x) = ∏ₜ p(yₜ|y<ₜ,Z,x)
怎么理解
Eᵥ 提取图像特征，Pθ 是连接模块。连续视觉 token 不是原始像素也不是固定词表文本；输出仍可用自回归语言目标训练。
阅读备注
线性投影、Q-Former、交叉注意力不是可随意替换的接口，token 数与训练阶段都影响代价。
动手自测
画出图像到 LLM 的 shape 流程，并比较 64 与 576 个视觉 token 的注意力开销。
