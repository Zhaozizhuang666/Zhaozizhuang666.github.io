扩散模型基础

理解 DDPM 的噪声预测，并区分与 Flow Matching 的联系和差别。

原稿整合约 5 分钟 · 不含实践更新于 2026-10-23
STUDY NOTES / 先读重点

重点、公式与解读

本章重点
前向过程向数据加噪；去噪网络在条件下恢复可采样的分布。
核心公式
xₜ = √ᾱₜ x₀ + √(1−ᾱₜ) ε；L = E‖ε − εθ(xₜ,t,c)‖²
怎么理解
ε 是标准高斯噪声，ᾱₜ 是累计保留信号系数，c 是条件。此处是 DDPM 常见噪声预测参数化，训练采样 t 后回归所加噪声。
阅读备注
扩散、score 建模与 flow matching 有联系，但目标和路径不等同；π 系列不能简单归为 DDPM。
动手自测
画出不同 t 的信噪比，并说明训练时知道 ε、采样时不知道 x₀。
概念对照：后面 Flow Matching 通过学习概率路径上的速度场生成样本。它与扩散模型有关联，但不能简单视为扩散的推广；采样效率取决于路径、求解器、步数与模型。
