企业标签不能代替岗位调研

大厂、创业公司、“独角兽”与上市公司可能同时拥有算法、数据、软件、硬件、交付和运营团队，但并非每家公司每个时期都招聘全部方向。估值、上市与组织状态会变化，本站不发布未经核验的独角兽名单。

官方入口与本次核查边界

2026-10-23 获取了以下官方入口 HTML，确认页面可获取不等于完整动态职位已加载，也不代表在招岗位或学历要求已逐项核实。

  • Figure Careers：页面说明招聘涉及 AI、engineering 与 design。动态职位详情另需进入核对。
  • 宇树招聘：可获取官方职位列表入口与详情路径；部分英文详情静态内容未返回完整 JD，应在官网实际打开。
  • NVIDIA Careers：平台与计算生态方向的官方招聘入口，需搜索 robotics、simulation、software 等关键词。
  • ABB Careers：工业自动化与机器人相关雇主调研入口，业务线与岗位需逐条确认。
  • 优必选官网：本次确认公司官网可获取；招聘入口从官网导航查找，未据此推断具体职位。

中国企业与更多目标的调研方法

可继续关注互联网/云平台机器人团队，宇树、智元、银河通用等机器人企业，以及优必选、埃斯顿等相关上市企业的官网招聘。这里是调研候选示例，不表示本站确认其当日在招、融资状态或具体学历限制。优先由公司官网进入招聘，核对主体和校招公告，避免将聚合站当成官方证据。

每条 JD 记录什么

记录官方 URL、抓取日期、职位名、团队、地点、校招届别、最低资格、加分项、岗位职责、实机/出差要求与申请状态。将每项能力对应到作品集证据，未知项写“待核实”。不记录或公开个人招聘联系人信息。
