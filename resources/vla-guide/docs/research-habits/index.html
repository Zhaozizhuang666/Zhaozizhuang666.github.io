重点、公式与解读

本章重点
阅读、记录、协作和表达都要保留可以追踪的证据。
核心方法
阅读、记录、协作和表达都要保留可以追踪的证据。
怎么理解
读论文记问题、方法、实验与局限；实验记录配置和结果；协作说明接口和负责人；汇报区分事实、解释与假设。
阅读备注
阶段和时间只是参考，按实际基础与官方要求调整；不以视频是否可播放作为验收条件。
动手自测
写一条含日期、改动、结果、解释与下一步的实验日志。

阅读随能力递进

大一先读教程、图和简单代码，尝试解释输入输出。大二阅读方法论文时先看问题、图表、实验任务与限制，再补公式。大三以后围绕一个项目读相关工作，研究阶段用问题组织文献地图，避免只按日期堆笔记。

每次学习留下可复查记录

记录日期、目标、来源、运行版本、结果和未解决问题。命令、日志和截图关联到具体实验 ID。对照实验保留完整配置，手工复制结果时同时保存原始文件。

一页论文笔记模板

论文题名、作者、年份、版本、官方链接:
它要解决的问题与适用前提:
输入、输出、训练目标和关键设计:
数据、基线、评价协议:
证据支持的结论与尚未覆盖的情况:
我能解释的部分 / 暂不理解的部分:
与当前项目相关的一次最小验证:

提出可回答的问题

求助时附目标、最小输入、预期行为、实际结果、版本和已尝试步骤。先排除接口错误，再讨论方法。组会汇报区分已完成、已观察和计划验证，不把预测写成结果。

协作与署名

用 issue 记录任务，用分支和 PR 讨论修改。项目开始时说明数据、代码与成果的归属和许可，署名按实际贡献与团队规范协商。阅读与复现要引用原作者，借助工具也需要自己核对输出。

节奏与支持

为课业、休息和反馈留出时间。遇到持续卡住的问题，缩小范围并请教老师或同学。科研能力来自多次有记录的验证，不要求某个年级就掌握全部前沿。
