动作、坐标系与控制频率

把模型输出变成机器人能执行的量，避免单位和坐标系错误。

新增教程约 6 分钟 · 不含实践更新于 2026-10-23
STUDY NOTES / 先读重点

重点、公式与解读

本章重点
位姿组合必须声明从哪个坐标系到哪个坐标系，动作表示与控制模式也要分开。
核心公式
pᴮ = Tᴮ_C pᶜ；Tᴮ_E = Tᴮ_C Tᶜ_E；Δt = 1 / f
怎么理解
上标是目标系、下标是源系。齐次坐标相乘可串联变换；f 为 Hz 时 Δt 单位为秒。10 Hz 的新观测每 0.1 秒到达，不能假设对应控制内环频率。
阅读备注
绝对位姿、增量位姿、关节位置和力矩语义不同；旋转增量的左乘右乘代表不同约定。
动手自测
使用已知基准点验证正向和逆向变换，并检查厘米和米混用的影响。

动作向量必须有完整定义

例如一个 7 维动作可以表示三维平移增量、三维旋转增量和夹爪开合。但同样的维度也可能对应绝对位姿或关节命令。必须同时记录：坐标系、单位、旋转表示、绝对或相对、夹爪范围、控制周期和底层控制器。

坐标变换的方向

设 T_base_camera 把相机坐标中的点映射到基座坐标，那么 p_base = T_base_camera · p_camera。矩阵乘法的左右顺序、行列向量约定以及是否需要求逆，都应通过一个已知点检验。不要凭变量名猜测定义。

旋转表示的取舍

  • 欧拉角直观，但有顺序约定、周期跳变与奇异性。
  • 四元数需要归一化，q 与 -q 表示同一旋转，直接回归时需考虑符号一致性。
  • 旋转矩阵与 6D 表示仍需保证解码后满足 SO(3) 约束。
  • 姿态误差适合用相对旋转的角度评价，不能只比较各分量差值。

预测 K 步不等于执行 K 步

模型可预测 K 个动作，但只执行前 H 个再获取观测，且 H ≤ K。H 越大通常能减少推理调用，却可能降低对扰动的响应。改变控制频率会改变 delta 动作的物理含义，重采样时必须检查平移、旋转和夹爪的插值规则。

实践任务

画出一条演示轨迹中的位置、姿态和夹爪曲线。通过正向和逆向变换验证坐标一致性。人为交换一个轴、改变角度单位，再检查可视化能否及时暴露错误。真机验证先在受限速度、受限工作空间和具备急停的环境完成。
