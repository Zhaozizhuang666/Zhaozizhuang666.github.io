数学最小集

掌握读 VLA 论文所需的最小数学集合，重点是刚体变换 — 这是 CV 转具身最常见的知识缺口。

原稿整合约 5 分钟 · 不含实践更新于 2026-10-23
STUDY NOTES / 先读重点

重点、公式与解读

本章重点
矩阵表示线性变换；条件概率描述已知信息后的不确定性；刚体变换把不同坐标系的几何量接起来。
核心公式
x′ = Rx + t；T = [R t; 0 1]；p(A|B) = p(A,B) / p(B)
怎么理解
R 是 3×3 旋转矩阵、t 是 3 维平移。齐次矩阵 T 为 4×4，乘 4 维列向量 [x;1]。条件概率公式要求 p(B)>0。变换组合的乘法次序不能交换。
阅读备注
旋转矩阵满足 RᵀR=I、det(R)=1。坐标轴方向、长度单位和相机时间必须统一；考研数学不能完整替代机器人几何。
动手自测
给点 (1,0,0) 施加绕 z 轴 90° 旋转，再平移 (1,2,0)，手算得到 (1,3,0)，用代码核对。
主题必须掌握资源
线性代数矩阵分解、特征值、投影、SVD；理解 attention 里矩阵乘法在算什么3B1B · 站外搜索 · MIT 18.06
概率统计条件概率、期望、高斯分布、KL 散度、最大似然、重参数化陈希孺教材；考研数学一已覆盖大半
最优化梯度下降族、Adam/AdamW、学习率调度、warmup、非凸直觉李宏毅课程前半
刚体变换旋转矩阵、四元数、欧拉角、齐次变换、SE(3)/SO(3)Modern Robotics 第 3 章
视觉几何相机内外参、针孔模型、坐标系变换、点云基础《视觉 SLAM 十四讲》前 7 讲
关于刚体变换：动作空间里的 6-DoF 位姿、末端朝向、坐标系转换，不懂这些读 VLA 论文会一直有隔膜感。但不需要学完整本机器人学，第 3 章加四元数的直觉就够起步。
