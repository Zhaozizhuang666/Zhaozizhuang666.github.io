核心方法

怎么理解
保存 commit、环境、数据来源、checkpoint 与实验配置。Stars 和 README 展示不能替代复现实测；合集用于发现，原仓库用于核验。
阅读备注
克隆成功不等于运行成功，下载权重也不等于拥有数据再分发权限。
动手自测
为一个仓库填出版本、许可、最小运行与结果核验四项。

LeRobot 值得特别说明

LeRobot 提供了统一的策略训练、数据处理和机器人集成接口。它把多种算法、数据格式、真机驱动统一到一个框架里。如果只能选一个仓库深入，选它。

信息渠道
  • arXiv cs.RO / cs.CV每天扫标题，每周精读一篇
  • 会议CoRL、RSS 是具身智能主场；ICRA、CVPR、NeurIPS 也要跟
  • 跟团队比跟关键词有效Physical Intelligence、DeepMind Robotics、Stanford IRIS、清华 TEA Lab
  • 中文公众号机器之心、量子位、深蓝具身智能
