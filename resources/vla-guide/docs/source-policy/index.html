怎么理解
可达性检查只说明某时某网络收到页面，不证明材料内容正确、视频可播放、无需登录或实验复现成功。记录来源和核查边界。
阅读备注
本次 HTTP 检查结果单独保存在资源核查清单；未知项不写已核验。
动手自测
找一条绝对化声明，改写为带条件、来源和适用范围的说法。

资料的三种状态

候选阅读：继承自原稿或社区整理，待核对题名、编号、作者和链接。官方资料：链接指向作者或项目官方渠道，仍需核对版本。复现实测：必须附源码 commit、环境、配置、数据与评测证据。网页能访问不代表论文内容正确，也不代表复现成功。

新论文收录

优先保留官方论文、代码和项目主页，不硬写易过期的星标数。题名和 arXiv 编号不一致时先标注问题，不能用 HTTP 200 证明内容正确。不把未来进展、未公开模型或商业宣传作为确定结论。

许可分别检查

代码许可、模型权重许可与数据许可是不同对象。课程、论文与第三方图片继续归原权利人所有。本站的开源许可不覆盖链接到的材料，也不为转载未授权内容提供许可。

怎样贡献一篇教程

  1. 说明读者起点、目标和前置章节。
  2. 给出能理解的原理及边界，引用一手来源。
  3. 实践内容注明版本、硬件、运行顺序和验收标准。
  4. 更新章节目录，运行构建与结构校验。
  5. 提交 PR，列出新增内容、参考资料与检查方法。
