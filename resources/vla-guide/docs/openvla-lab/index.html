OpenVLA 复现工作单

从 checkpoint 推理到 LIBERO 评测，逐步建立可追溯的基线。

新增教程约 6 分钟 · 不含实践更新于 2026-10-23
STUDY NOTES / 先读重点

重点、公式与解读

本章重点
复现链分为加载推理、动作检查、环境适配、固定基线和微调比较。
核心公式
Δ = 同协议新方法成功率 − 同协议基线成功率
怎么理解
差值只有在场景分布、种子、checkpoint 选择和试验预算一致时才有可比较含义；保留原始成功失败记录。
阅读备注
未实际运行的步骤是工作单，不是复现实测结论。
动手自测
只在一个任务上完成最小闭环，保存版本、输入样本、动作统计及日志。

目标和前置条件

目标是按官方仓库支持的环境，完成一次 checkpoint 推理、一次小数据微调和一套固定协议评测。需要 Linux / GPU 经验、PyTorch 基础及动作归一化知识。显存由精度、序列长度、batch size、LoRA 配置与图像输入共同决定，先测小规模再预算。

第一阶段：环境与版本

阅读官方 README，固定源码 commit、模型 revision 和依赖。使用独立环境，不把 OpenVLA、OFT 和 openpi 的依赖混装。记录 GPU、驱动、CUDA、PyTorch 与 attention 实现。环境安装成功后先跑官方最小推理，不直接启动长训练。

第二阶段：离线检查

  1. 加载一条真实观测，核对图像方向和指令模板。
  2. 确认选中的 unnorm_key 属于目标数据集。
  3. 查看输出动作的维度、范围、夹爪含义与坐标系。
  4. 连续推理若干帧，把动作曲线与演示动作对照。

第三阶段：小样本微调

先用极小数据确认 loss 可下降，保存 checkpoint 并重新加载。然后扩大训练规模。比较不同训练步数时必须保留相同评测协议，避免把 checkpoint 选择变成对测试集调参。

第四阶段：LIBERO 闭环

直接从官方评测说明选择受支持的 suite。先跑单任务单 rollout 排除接口问题，再运行预先设定的任务集合。记录初始状态、任务顺序、随机种子和视频。结果对不上时依次检查：数据与 checkpoint、图像预处理、动作反归一化、环境版本、控制设置。

验收成果

提交 README、环境锁定文件、训练与评测配置、日志摘要、逐任务结果和失败视频。复现结果可以低于论文，但需要解释协议差异和未解决的问题。不要把学习工作单当作未经实测的通用 shell 配方。

官方入口：OpenVLA、OpenVLA-OFT。
