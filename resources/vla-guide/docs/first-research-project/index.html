本科生的第一个科研项目：八周工作单

用有限时间完成问题定义、基线、单变量实验和报告，适合大二以后。

重点、公式与解读

本章重点
八周工作单控制范围，先复现一个可观察结果再做一项改动。
核心方法

怎么理解
前两周环境与小样本，中间三周基线与改动，后面三周评测、失败分析、复现与报告；遇依赖阻塞及时缩减。
阅读备注
阶段和时间只是参考，按实际基础与官方要求调整；不以视频是否可播放作为验收条件。
动手自测
为每周写一个完成定义，设置资源或时间超限时的替代任务。

选择一个可完成的问题

前置是至少完成一个分类或小型策略项目。没有这项基础时，先沿大一大二路线补齐。八周是组织工作的参考，不是产出保证；每周投入可从 3–5 小时起，根据课程与环境难度顺延。

第 1–2 周：资料和最小基线

选一个已有数据和官方实现的小问题，阅读论文摘要、方法图与评测设置。完成单样本推理和数据可视化，记录环境与随机种子。选题例子：固定图像分类器时，不同程度遮挡如何改变各类别错误率。

第 3–4 周：复现与协议

固定数据划分、模型、预处理、评价指标和资源。只在训练与验证数据上决定设置，测试数据留到最终比较。跑通基线并检查失败样本，写明与原实验不同的地方。

第 5–6 周：一个主要变量

以遮挡位置或强度为变量，控制其余设置。保存每样本预测与分组规则。结果没有提升也可以回答“什么情况下失效”，不为制造亮点同时改变模型和数据。

第 7 周：分析与复查

区分观察事实、可能原因和未经验证的解释。确认样本数量、错误标签和数据泄漏。请同学按 README 运行一次，修正隐藏路径和缺失依赖。

第 8 周：交付与后续

提供代码、运行环境、结果文件、图表脚本和两到四页报告。用五分钟讲清问题、协议、结果、局限和下一步。若迁移到 VLA，先把问题改写为具体观测扰动或延迟，再评估仿真接口和资源。

可以提交什么

该工作可以作为课程项目、组会交流或进入实验室的作品。是否形成研究贡献，需要结合已有工作和导师反馈判断，不能用八周日程承诺论文或录取结果。
