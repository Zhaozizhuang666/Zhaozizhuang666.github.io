LINUX SYSTEMS

Linux 系统学习路线

Shell、系统管理、存储、网络、安全、性能、容器与内核。

历史知识点：CentOS 5、SysV、GRUB/LILO、RPM/YUM、ifconfig/netstat、at/cron、/proc。

现代知识点：systemd/journald、iproute2、nftables、cgroup v2、namespaces、SELinux/AppArmor、容器与 eBPF。

推荐学习路线

  1. 命令行与文件系统

    掌握终端、路径、FHS、文件查找、文本处理、管道、重定向、引号和环境变量；读懂基础 Bash 脚本。

    重点：Bash、Coreutils、man-pages、权限与链接。

  2. 用户、权限与进程

    理解用户组、sudo、文件权限、ACL、进程状态、信号、作业控制，以及 /proc 和 /sys 的诊断用途。

    重点：最小权限、进程生命周期、命令退出码和日志。

  3. 启动、服务与日志

    学习 UEFI/GRUB 启动路径、systemd unit、依赖、目标、服务状态和 journald；用日志和服务状态解释启动故障。

    重点：systemctl、journalctl、启动依赖和恢复流程。

  4. 存储与文件系统

    掌握块设备、GPT 分区、挂载、/etc/fstab、swap、LVM、软件 RAID、ext4/XFS/Btrfs 的用途和基本检查；了解 LUKS 加密。

    重点：设备识别、容量、inode、I/O、备份与恢复。

  5. 网络与防火墙

    从 TCP/IP、路由、DNS、端口和套接字开始，学习 NetworkManager、iproute2、ss、抓包、nftables 及发行版防火墙管理。

    重点：分清链路、路由、解析、监听、策略和应用层故障。

  6. 系统安全

    建立 SSH、sudo、补丁、密钥、审计和安全基线；按发行版了解 SELinux 或 AppArmor，并理解 Linux capabilities、namespaces、seccomp 的边界。

    重点：默认拒绝、最小权限、可审计变更和回滚。

  7. 观测与性能

    结合负载、采样周期和日志观察 CPU、内存、磁盘、网络与进程；逐步学习 PSI、cgroup v2、perf 和 eBPF 工具。

    重点：先建立基线，再定位饱和资源与因果关系。

  8. 自动化、容器与虚拟化

    用可审查的 Bash 或 Ansible 重复配置；理解镜像、rootless 容器、Podman、systemd 集成、KVM/libvirt，以及容器依赖的 namespaces 与 cgroups。

    重点：幂等性、凭据保护、资源限制和运行时隔离。

  9. 内核与深入排障

    从系统调用、内核日志、模块、设备、文件系统和网络栈入手；需要内核开发时再继续阅读源码、追踪点和构建文档。

    重点：以 Linux Kernel Documentation 和对应版本源码为准。
