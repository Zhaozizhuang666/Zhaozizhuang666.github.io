Robotics End-to-End Model Evaluation Engineer

Spirit AI · 千寻智能

千寻智能（北京）科技股份有限公司

Spirit AI develops embodied foundation models, including the open-source Spirit V1.5 vision-language-action (VLA) model.

My evaluation work connects benchmark design, simulation, real-robot testing, and data review. I standardize test conditions and success criteria, document failures, and organize evaluation evidence to support model iteration.

  • Benchmark development. Define tasks, scenario configurations, initial states, and success criteria to make evaluation runs reproducible and model comparisons consistent.
  • Simulation evaluation. Build simulation scenarios and task environments, with attention to inference interfaces, rollout execution, and closed-loop evaluation.
  • Automated evaluation pipelines. Connect test execution, log and video collection, result organization, and reporting in repeatable evaluation workflows.
  • VLA metric design. Structure task-success, execution-time, and intervention records alongside logs and videos to support failure analysis and review.
  • Engineering tools · Bash & Agent Skills. Develop and refine scripts and SOPs for environment checks, robot startup diagnostics, device-resource troubleshooting, and configuration recovery; explore reusable Agent Skills built from these workflows.
