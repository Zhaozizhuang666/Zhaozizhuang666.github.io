01 · GETTING AROUND

Usage 如何开始

Start at Home for the personal profile, current robotics evaluation work, projects, learning, research, community work, and public reports. Open Library when you need a competition or journal directory. The site is English-first, with concise Chinese context where it helps.

  1. Choose a section from the top navigation or use the skip link for keyboard access.
  2. Follow the source link attached to a project, report, paper, patent, competition, or journal entry.
  3. Use Xiaoyi for a first explanation, then inspect the returned reference before relying on a detail.
The site is a curated personal workspace. It does not claim to be a complete directory, a live deadline tracker, or a replacement for an official announcement.

02 · APPEARANCE

Theme 外观与阅读状态

Use the compact EN/中文 control beside the theme button to switch site copy. Your choice is remembered across Home, Library, Guide, and reloads. Source titles, names, and Xiaoyi conversation messages remain unchanged; no external translation service is called.

The header control cycles through Auto, Light, and Dark. Auto follows the visitor's operating-system appearance. An explicit Light or Dark choice is saved locally and remains consistent when moving between Home and Library or refreshing either page.

Choosing Auto removes the explicit override. Xiaoyi follows the selected appearance: its Auto outfit stays normal, explicit Light is lively, and explicit Dark is sleepy. A reduced-motion preference disables entrance motion while keeping every section available.

On desktop, opening Xiaoyi gives the page the remaining space and scales it toward the opposite side. The drawer can dock left or right; a fresh page visit starts on the right. Dragging changes the position for the current visit and the matching drawer side.

03 · COMPANION

Xiaoyi Website Knowledge Entry · 小艺智能体

Xiaoyi is the collapsible companion in the page edge. Hover or focus the small edge control to preview it, then open the conversation. On a desktop drawer, the page remains visible in the available space; on a phone, the conversation behaves as a modal and keeps focus inside the panel.

How to ask well

  • Start with one subject: “What is VLN?” or “How should I compare SR and SPL?”
  • Use a follow-up such as “好的，把链接给我” to request sources for the current subject.
  • Change topic explicitly when needed: “Now leave VLN and explain VLA.”
  • Use New chat when you want a clean context.
Local Xiaoyi uses the checked-in knowledge files and retrieval logic. It does not train itself, browse the web in real time, or guarantee that a current rule, deadline, model capability, or result is correct. Treat its answer as a sourced starting point and verify important claims.

One useful path

Ask about VLN → open the cited paper on visually grounded navigation → ask about SR and SPL → compare the metric definitions with the task protocol before using them in an evaluation. A link is evidence to inspect, not a substitute for the protocol.

04 · REFERENCE

Library 知识库

The Library has two searchable directories:

Competitions86 indexed entries · school-level A, B1, and B2 labels Journals6,430 indexed entries · first- and second-batch lists

Search by name, organizer, or keyword; use the available filters; then open the source or search entry on each card. The competition labels come from the supplied Shanxi Institute of Technology directory and should not be read as a universal national ranking. Journal batches are directory classifications, not a judgment of article quality.

The technical collection behind Xiaoyi changes as it is curated. Its entries retain source type and links; they are not a hardcoded count or a claim of complete coverage.

05 · OPTIONAL ONLINE MODE

Models 模型接入

The checked-in site has no live model endpoint configured. Knowledge mode remains available without a server. The interface can list DeepSeek, Qwen, Kimi, GLM, or a server-registered compatible provider only after an operator deploys the optional Worker and configures a server-side secret.

GitHub Pages serves the static frontend; it does not run the Worker. Provider keys must stay in Wrangler secrets, never in this repository or in browser code. The server validates allowed origins, providers, models, message size, and request limits, and returns clear unavailable or upstream-error states.

A model appearing in a server response means that a configuration exists. It does not prove account balance, model permission, current uptime, or answer quality.

06 · KEEPING IT RELIABLE

Maintenance 维护与发布

For a local preview, run a static server from the repository root:

python3 -m http.server 8000
# open http://localhost:8000/

Before a release, run the behavior contracts and then complete the three QA rounds in QA.md:

node --test tests/*.test.mjs

Review source links, theme persistence, Xiaoyi open/close and left/right docking, mobile layout, library filters, reduced motion, and the absence of broken assets. Commit the release, push the intended branch, wait for GitHub Pages to deploy, then verify both public pages in a fresh browser. A successful local test does not prove that a public deployment or optional model service is live.

The free Pages address uses the repository owner name, currently zhaozizhuang666.github.io. “zizhuang.zhao” is a display name; it cannot replace the GitHub Pages hostname without a separately owned custom domain and DNS configuration.
