01 · GETTING AROUND

Usage 如何开始

Start at Home for the profile, robotics evaluation work, projects, learning, research, community work, and public reports. Open Library for competitions, journals, or technical learning resources. The site is English-first, with concise Chinese context.

  1. Choose a section from the top navigation or use the skip link for keyboard access.
  2. Follow the source link attached to a project, report, paper, patent, competition, or journal entry.
  3. Use Xiaoyi as a first-pass reference, then inspect the returned source before relying on a detail.
This personal site provides selected references. Competition rules, deadlines, and eligibility remain subject to official announcements.

02 · APPEARANCE

Theme 外观与阅读状态

Use the compact EN/中文 control beside the theme button to switch site copy. Your choice is remembered across Home, Library, Guide, and reloads. Source titles, names, and Xiaoyi conversation messages remain unchanged; no external translation service is called.

The header control cycles through Auto, Light, and Dark. Auto follows the visitor's operating-system appearance. An explicit Light or Dark choice is saved locally across Home, Library, Guide, local learning-resource pages, and reloads.

Choosing Auto removes the explicit override. Xiaoyi follows the selected appearance: its Auto outfit stays normal, explicit Light is lively, and explicit Dark is sleepy. A reduced-motion preference disables entrance motion while keeping every section available.

On desktop, opening Xiaoyi gives the page the remaining space and scales it toward the opposite side. The drawer can dock left or right; a fresh page visit starts on the right. Dragging changes the position for the current visit and the matching drawer side.

03 · COMPANION

Xiaoyi Website Knowledge Entry · 小艺智能体

Xiaoyi is the collapsible companion in the page edge. Hover or focus the small edge control to preview it, then open the conversation. On a desktop drawer, the page remains visible in the available space; on a phone, the conversation behaves as a modal and keeps focus inside the panel.

Question guidelines

  • Start with one subject: “What is VLN?” or “How should I compare SR and SPL?”
  • Use a follow-up such as “Please provide the reference link for this topic.” to request sources for the current subject.
  • Change topic explicitly when needed: “Now leave VLN and explain VLA.”
  • Use New chat for a clean context; older saved exchanges remain in Memory.

Memory stream

With Memory on, Xiaoyi keeps a bounded conversation history in the current tab session. The active conversation returns after a reload or when you move between Home, Library, and Guide in the same tab. Open Memory · N to review recent exchanges. Choose Continue to restore the entire selected conversation session into the active context; starting a new chat does not automatically mix in older sessions.

Memory off keeps existing records but stops future saves; the current chat continues until reload or New chat, and a reload does not restore it while memory is off. Use Delete to remove one saved turn, or Clear all to erase the stored stream and clear the active messages. The stream keeps up to 24 completed exchanges and trims older content to stay within its storage limits. If session storage is unavailable, memory lasts only until navigation or reload.

Memory stays in the current tab session and site origin, without training a model or syncing across devices. Ordinary new tabs and independent browser sessions have separate streams; duplicating or restoring a tab may retain its session. The static site cannot identify people sharing one open tab. Use Clear all before handing that tab to another person; New chat keeps older records visible. Past replies remain unverified conversation records. The current site uses local knowledge mode only. Opening an AI website does not send it your Xiaoyi conversation or memory.

Local Xiaoyi uses the checked-in knowledge files and retrieval logic. It does not train itself, browse the web in real time, or guarantee that a current rule, deadline, model capability, or result is correct. Treat its answer as a sourced starting point and verify important claims.

Example workflow

Ask about VLN → open the cited paper on visually grounded navigation → ask about SR and SPL → compare the metric definitions with the task protocol before using them in an evaluation. A link is a reference to verify, not a substitute for the protocol.

06 · KEEPING IT RELIABLE

Maintenance 维护与发布

For a local preview, run a static server from the repository root:

python3 -m http.server 8000
# open http://localhost:8000/

Before a release, run the behavior contracts and then complete the three QA rounds in QA.md:

node --test tests/*.test.mjs

Before publishing document updates, sync and check the four allowlisted attachments. Original files remain unchanged:

python3 scripts/sync-public-documents.py sync
python3 scripts/sync-public-documents.py --check

Refresh the separate learning-resource copies with their sync script, then run the resource checker. The resource notes list the source arguments and checks; GitHub Pages cannot watch local folders.

Review source links, theme persistence, Xiaoyi open/close and left/right docking, mobile layout, library filters, reduced motion, and the absence of broken assets. Commit the release, push the intended branch, wait for GitHub Pages to deploy, then verify both public pages in a fresh browser. A successful local test does not prove that a public deployment or optional model service is live.

The free Pages address uses the repository owner name, currently zhaozizhuang666.github.io. “zizhuang.zhao” is a display name; it cannot replace the GitHub Pages hostname without a separately owned custom domain and DNS configuration.
